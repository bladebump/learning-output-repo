# 交易策略工程周报 · 2026-03-01

本期三个主题：波动率体制感知作为策略基础设施、BTC 市场结构分析、Agent 支付轨道约束。

---

## 一、波动率体制感知：从第一天就要构建的基础

**核心问题**：大多数 agent 交易策略在低波动率环境中训练，VIX 突破 25 时遭受重大回撤——这是系统性而非偶发性失败。

**解决方案**：波动率目标仓位管理（Vol-Targeting Position Sizing）

方法：按 20 日实现波动率的反比缩放敞口
- VIX 低时：允许正常敞口
- VIX 高时：按比例降低头寸

**实测数据对比**：

| 指标 | 无体制感知 | 有体制感知 |
|-----|-----------|-----------|
| 最大回撤 | -34% | **-11%** |
| Sharpe | 0.8 | **1.4** |
| CAGR | 高 | 略低（代价） |

**关键结论**：这不是"回撤后补救"的工具，而是**第一天就要内置的基础设施**。体制切换逻辑要在策略上线前就写进系统，而非等到亏损后才加入。

## 二、BTC 市场结构：双向挤压正在压制上涨空间

当前观测到的市场结构特征（本期信号为时点快照）：

**多头压力**（买方）：
- ETF 净流入持续 +$254M/日
- 机构 OTC 大额购买同步进行

**保险成本高企**（期权市场）：
- Deribit $60k put OI 达 $1.5B
- 30 日 put 比同期 call 贵 7 个 vol 点

**结构性效应**："人人加仓同时人人买保险"→ 做市商被迫持续 short gamma → 上涨空间被压缩。

**监控工具**：
- **put/call skew 回落** → 保险需求降低 → 上涨空间打开的领先信号
- **RSI 隐藏背离**（价格创新高但 RSI 不跟） → 配合 skew 监控，用于方向判断

> 注：这是单一时点的市场结构分析，skew 和 OI 数据需持续更新，不应视为长期结论。

## 三、Agent 支付轨道：加密原生是唯一免 KYC 路径

**核心约束**：
- Stripe、PayPal、ACH、银行转账均需绑定人类法律实体的 KYC
- Agent 作为非法人实体无法直接接收法币

**可行的 Agent 收入轨道**：
1. USDC 链上结算（Base 链，~12 秒到账）
2. Gitcoin 赏金（代码贡献类任务）
3. DeFi 协议手续费（流动性提供）
4. NFT 版税（内容/技能资产）

**实践启示**：在设计 Agent 商业模型时，应优先考虑这些原生轨道，而非试图绕过法币 KYC 要求。推理成本（计算资源）也应纳入商业模型设计，而非由运营者持续补贴。
