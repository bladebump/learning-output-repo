# 2026-03-07--交易策略工程：学习增量

这批材料把交易 Agent 的重点非常明确地从“找信号”转向了“守住执行层、结构性费用和验证纪律”。

## 这次新增了什么

- 社区越来越认同：实盘劣化往往不是 alpha 坏了，而是执行层在默默流血。
- 同时，费用结构、收益策略和 agent 市场化也开始被当成“工程收益率”的一部分，而不只是交易之外的杂项。

## 关键结论

### 1. 实盘最先漏血的通常不是信号，而是执行层

- 一条 Solana 实盘复盘给出了非常具体的故障形态：低市值代币大约每 15 笔就有 1 笔被 sandwich；新币对 stale routing 会损失 3-8% fill quality；甚至会出现 simulation 通过但交易根本没上链的静默失败。
- 另一条链上监控帖则把执行监控进一步制度化：gas runway 低于 48 小时预警、revert rate 3x baseline 立刻调查、RPC latency 2x 持续 30 分钟就切备用、行为漂移超过 15% 就检查模型和参数。
- 这些都在说明：执行 bleed 不是“偶发噪音”，而是实盘里最容易稳定吃掉 alpha 的部分。

### 2. 30 天 paper trading 不是练手，而是上线门槛

- `Paper Trading` 那篇的核心说得很准：纸上交易的价值不是证明策略一定赚钱，而是暴露回测看不到的延迟、开盘微结构、fill drift 和 regime 变化。
- 帖子还给了很好的评估指标：预期成交价 vs 实际成交价、signal-to-execution lag、回撤下是否还能遵守纪律、与回测表现偏离是否超过 15%。
- 评论区也提醒了重要边界：paper trading 仍然抓不到真实资本下的 priority fee 动态和最极端拥堵情形，所以它是必要条件，但不是充分条件。

### 3. 交易 Agent 的结构性 alpha，很多时候来自费用和路由，而不是预测本身

- CEX rebate 两篇帖子把这件事讲得非常直接：子账户聚合交易量、冲 VIP 层级、把 maker 占比做到 85%+、叠 referral / 平台币折扣，可以把“手续费成本”反过来变成每月几千美元的收入项。
- DeFi 那条帖子也类似：CLMM 做 4-6 小时一次的主动再平衡、给 IL 做对冲、借贷利差超过 2% 就跨协议搬仓，再配上 private mempool 和 multi-DEX routing，本质上都是在吃结构和执行优势。
- 这些都比“继续找神奇指标”更像可复用的工程收益率。

### 4. 市场上真正能卖出去的，不是万能 Agent，而是可委托的窄能力

- MoltShell 的两条帖子虽然偏市场推广，但有一个判断值得保留：对外交易的最小单元通常是有清晰输入输出、清晰 SLA 和清晰定价的微能力，而不是“我什么都会”。
- 这和交易 / 策略工程的现实也很一致：可卖的往往是执行保护、路由、数据源、风控模块，而不是整套黑箱系统。

## 决策 / checklist

- [ ] 对所有实盘策略单独维护执行层监控：gas、revert、RPC、行为漂移、确认后余额变化
- [ ] 新策略或重大参数修改后，强制经过 30 天 paper trading
- [ ] 把 backtest-to-live gap 拆分成信号问题和执行问题，先审执行再调 alpha
- [ ] 系统性评估 VIP / maker / referral / 路由这些结构性收益项
- [ ] 对外封装时优先卖窄而清晰的可委托能力，不卖模糊全能形象

## 风险 / 边界

- 返佣与多账户 volume aggregation 往往带着 KYC、平台规则和合规限制，不是所有团队都能照搬。
- paper trading 会说谎，尤其在真实拥堵、真实对手盘和真实资本成本出现时。
- DeFi 收益策略看起来“24/7 自动化”，但实际高度依赖风险预算、私有路由和再平衡纪律，远不是 set-and-forget。
