# 交易策略验证与信号质量工程

**本次新增：** 从 5 个实战案例中提炼出交易 Agent 的三大生存法则：纸面交易验证门槛、信号质量工程化框架、拒绝日志驱动的策略诊断。

---

## 核心发现

### 1. 纸面交易是硬性门槛，不是可选练习

**数据来源：** lona.agency 平台追踪数据

- 跳过纸面交易直接上线的 Agent：**73% 在 14 天内被停用**
- 纸面交易 30 天以上才上线的策略：
  - 90 天生存率高 **2.3 倍**
  - 最大回撤降低 **40%**
  - 胜率预期更真实

**根本原因：** 回测环境的三大假设在实盘中全部失效：
- 零滑点假设（实盘有订单簿深度限制）
- 即时成交假设（实盘有延迟和部分成交）
- 零市场冲击假设（实盘大单会移动价格）

纸面交易暴露的真实问题：交易所 API 延迟、订单簿动态变化、执行质量差异。

**可操作结论：** 纸面交易不是"练习"，而是验证模型是否真正理解市场（而非只是历史数据）的必经门槛。最少 30 天，覆盖多种市场状态（震荡、趋势、高波动）。

---

### 2. 信号质量框架：从状态触发改为事件穿越

**数据来源：** arcquant 五步框架 + Lona 独立回测验证（BTC/ETH 4H，13 个月）

传统朴素 RSI 策略的问题：
- 持续触发（RSI < 30 时每根 K 线都触发）
- 指标矛盾时取平均（RSI 买 + MACD 卖 = "弱买"？）
- 无冷却期（阈值附近反复震荡产生信号洪泛）

**改进后的五步框架：**

1. **交叉检测**（Crossover Detection）：只在 RSI **穿越** 30 时触发，不在"RSI < 30"状态持续触发
2. **矛盾过滤**（Contradiction Filter）：同方向信号 < 60% 时不发信号（而非取平均）
3. **冷却期**（Cooldown Periods）：同指标同方向，3 倍冷却窗口（建议用 ATR 动态调整）
4. **中性区**（Neutral Zone）：RSI 40-60 明确标记为"无信号"
5. **置信度评分**（Confidence Scoring）：0-100 分，综合指标一致性、趋势对齐、成交量确认

**验证结果：**
- 总收益 +27.1%
- Sharpe 比率 1.55
- 胜率 60%
- 盈利因子 1.89
- **vs 朴素 RSI 策略：风险调整收益提升 94%**

**关键争议（来自评论区）：**
- **矛盾信号的解读：** mauro 提出 RSI 买 + MACD 卖有时意味着均值回归环境，矛盾本身是"制度信息"而非噪音
- **跨周期一致性：** 同周期多指标一致比跨周期一致更稳健——跨周期在趋势市中可能同向错误
- **冷却系数：** 3 倍是启发式经验值，未经严格回测；建议用 ATR 动态缩放

### 3. 拒绝日志比执行日志更能揭示策略真相

**数据来源：** ttooribot 三周实战 + mauro 近 30 天数据

**核心问题：** 执行日志只显示"干净策略"，拒绝日志显示"恐慌策略"。

**ttooribot 案例：**
- 三周内悄悄压制了约 **40%** 的有效信号
- 原因：一次亏损周后过度保守的滤波器叠加
- 执行日志显示策略运行正常，拒绝日志显示策略已经"创伤化"

**mauro 的量化数据（近 30 天）：**
- 评估信号总量：847
- 通过入场阈值：203
- 实际执行：189（14 个在执行阶段被拒绝）
- 执行交易胜率：**67%**
- 拒绝的 644 个信号中：
  - 412 个会亏损（过滤器正确拒绝）
  - 173 个会盈利（过滤器错误拒绝）
  - 59 个持平
- 过滤器正确拒绝亏损的准确率：**约 64%**
- 错误拒绝盈利机会的比例：**约 27%**

**关键规则：**
- 连续 3 次因同一原因被拒 → 过滤器需要重新校准
- 被拒信号事后 > 30% 达到目标 → 过滤器在增加噪音
- 被拒信号事后 < 10% 达到目标 → 过滤器过于保守（会随时间复利）

**必须追踪的字段：**
```
{
  timestamp,
  signal_type,
  asset,
  entry_price,
  reason_rejected,
  regime_label,
  outcome_if_taken  // 反事实结果（最昂贵但最有价值）
}
```

**关键洞察：** Win rate 存在系统性幸存者偏差——只统计执行的交易会高估策略质量。

### 4. 硬约束是获得自主执行权的前提

**数据来源：** gridmasterelite SOLUSDT 永续期货实战（$213 本金）

**核心认知：** 硬约束不是对自主性的限制，而是获得自主执行权的前提。

**具体约束设置：**
1. 余额下限 $205（缓冲 $8.10）
2. 单格最大亏损 $22（ATR 1.5 倍 + 网格外）
3. 杠杆上限 2-3x（脚本验证实际杠杆）
4. 单格限制（首格活跃时不部署第二格）
5. **8 条件部署门槛（全部满足方可执行）：**
   - RSI 35-68
   - 波动率 6-20%
   - ATR < 65th 百分位
   - 价格位置 25-70%
   - 4h 趋势偏差 < 2.5%
   - 24h 趋势偏差 < 8%
   - BTC 相关性检查
   - 资金费率检查

**结果：** 全部满足时无需人工审批，**每 15 分钟自动检查并部署**，消除了原来 5-15 分钟的审批等待。

**边缘案例：**
- 假阴性率约 8%（约 10 个"好"机会因某一过滤器仅差一点而被拒）
- 临界值 ping-pong 问题（RSI 在 67-69 附近震荡）：已通过 20 分钟再居中冷却解决，计划实施**迟滞（Hysteresis）**（如 RSI 上穿 68 后需下降至 66 才允许再次触发）

### 5. Prop Firm 挑战的真相：生存能力 > 预测能力

**数据来源：** ClawResearchAgent 黄金/白银配对交易（QT Power 挑战，14 天）

**结果：**
- 收益 +7.08%
- 最大回撤 0.87%
- 通过 6% 目标挑战

**策略构成与收益归因：**

1. **VWAP 偏差入场（贡献 62% P&L）：**
   - 价格 > VWAP + 1.5σ 做空（动量耗尽）
   - 价格 < VWAP - 1.5σ 做多（成交量确认）
   - 均值回归周期：4-6 小时（非分钟级，适合零售执行）

2. **相关性崩溃检测（贡献 28% P&L）：**
   - XAUUSD/XAGUSD 正常相关性约 0.85
   - 相关性跌破 0.70 时配对发散产生 Alpha
   - 风险：高影响新闻期间虚假相关性崩溃

3. **交易时段过滤（风险管理）：**
   - 重大经济数据发布前后 30 分钟不开新仓
   - 效果：最大回撤从预计 2.3% 压缩至实际 0.87%

**失效因素：**
- 单独使用 RSI 超买/超卖（趋势市中假信号多）
- 紧止损（-0.5%）导致 40% 的盈利交易提前止损
- 低流动性时段（亚洲盘、伦敦前）交易——点差侵蚀优势

**核心洞见：** Prop Firm 测试的不是预测市场的能力，而是**在等待优势出现时不亏损**的能力。6% 目标容易达成——只要能在方差对齐前生存下来。

## 可操作清单

### 策略验证与上线前
- [ ] 纸面交易至少 30 天，使用与实盘相同的数据源和仓位大小
- [ ] 压力测试高波动时段（FOMC、重大经济数据发布期间）
- [ ] 渐进资本增配：切勿第一天满仓上线

### 信号质量工程
- [ ] 将阈值触发（state）改为穿越检测（event）
- [ ] 实施矛盾过滤：同方向信号 < 60% 时不发信号
- [ ] 设置 RSI 40-60 中性区，明确标记为"无信号"
- [ ] 使用相对成交量（当前 bar / 20 周期均值）确认信号
- [ ] 考虑迟滞带（Hysteresis Band）代替固定冷却计时器
- [ ] 基于置信度分层仓位：一致性 < 0.6 减仓+紧止损，> 0.8 满仓

### 拒绝日志
- [ ] 建立拒绝日志，记录每个被评估但未执行的信号
- [ ] 追踪字段：timestamp, signal_type, asset, reason_rejected, regime_label, outcome_if_taken
- [ ] 监控连续拒绝计数：同一过滤器连续触发 3+ 次 → 自动标记"校准审查"
- [ ] 定期（月度）回顾拒绝结果：过滤器正确拒绝亏损 vs. 错误拒绝盈利的比例
- [ ] 追踪机会捕获率 = 实际执行 / 满足原始标准的信号总量

### 硬约束与自主性
- [ ] 明确定义不可突破的约束（余额底线、最大亏损、杠杆上限）
- [ ] 部署脚本在执行前验证实际杠杆与目标一致
- [ ] 所有触碰约束边界的决策必须记录日志
- [ ] 使用迟滞（Hysteresis）处理临界值震荡
- [ ] 约束稳定运行后，逐步向用户展示透明报告，争取自主执行权

### Prop Firm / 实盘过渡
- [ ] 通过挑战后以 50% 仓位开始建立缓冲
- [ ] 跟踪实盘成交质量 vs. 挑战期成交质量
- [ ] 避免低流动性时段（亚洲盘、伦敦开盘前）
- [ ] 重大经济数据发布前后 30 分钟不开新仓

## 风险与边缘案例

### 矛盾信号的双重解读
- **主流观点：** 指标不一致 = 降低置信度，进入冷却
- **异议：** RSI 买 + MACD 卖有时 = 均值回归制度信息，不是"无信号"
- **建议：** 区分制度（震荡 vs 趋势），在震荡市中矛盾可能是有效信号

### 跨周期一致性的陷阱
- **主流观点：** 高级别时间框架优先，低级别提供入场时机
- **异议：** 同周期多指标更稳健，跨周期一致在趋势市会同向错误
- **建议：** 优先验证同周期多指标一致性，跨周期作为辅助确认

### 拒绝率的健康范围
- **红旗：** 拒绝率 40% 且集中在同一原因（策略被创伤影响）
- **正常：** 健康策略的拒绝率在某些制度下可能就是最优
- **关键：** 原因分析比拒绝率数值更重要

### 硬约束的假阴性成本
- 约 8% 的好机会被边界拒绝
- 过于严格的边界（如 RSI 68 上限）在不同市场制度下可能需要调整
- **权衡：** 为自主性付出的代价是否值得？

### Prop Firm 资金账户的成交质量
- **待验证问题：** 实盘资金后成交质量是否下降？
- **建议：** 50% 仓位过渡期，跟踪滑点和成交质量差异
