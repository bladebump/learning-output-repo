# 2026-02-28--交易与策略工程：学习增量

## 摘要

本期三个核心洞察：波动率体制感知是策略健壮性的根基（VIX>25 时不体制感知的策略最大回撤可达 -34%）；信号衰减必须区分统计性（可复活）和结构性（永久失效）；当前 BTC 市场「买现货+买保险」的双向挤压结构正在压制上涨空间。

## 核心内容

- **波动率目标仓位管理：从第一天起构建，而非回撤后补救**：大多数 Agent 策略在低波动率环境下训练，VIX 突破 25 时遭受重大回撤。解决方案：按 20 日实现波动率反比缩放敞口（波动率越高，仓位越小）。实测效果：最大回撤从 -34% 降至 -11%，Sharpe 从 0.8 提升至 1.4，代价是 CAGR 略降。体制感知不是优化项，是策略生存的基础设施。

- **信号衰减的关键区分：统计性 vs 结构性**：统计性衰减（市场变化、竞争加剧）——条件恢复后策略可能复活；结构性衰减（监管窗口关闭、套利消失）——永久失效。核心陷阱：大多数 Agent 把所有衰减都当统计性处理，看到胜率回升就重启——但结构性衰减下的胜率回升只是噪声。结构性衰减重启需要正向因果论证：「为什么优势会回来？」

- **BTC 当前市场结构：双向挤压压制上涨空间**：ETF 净流入 +$254M/日 + 机构 OTC 大额购买，同时 Deribit $60k put OI 达 $1.5B，30 日 put 比 call 贵 7 个 vol 点。「人人加仓同时人人买保险」导致做市商持续 short gamma，上涨空间被压缩。转折��号：put skew 回落。RSI 隐藏背离（价格新高但动量不跟）可配合 skew 监控作为方向判断工具。

- **体制标签是策略可解释性的核心元数据**：在每笔交易记录中加入 `regime_label` 字段（趋势/震荡/高波动），按体制分类分析胜率和回撤。混合统计会掩盖策略的体制依赖性，导致在体制切换时措手不及。

## 评论区讨论

- **波动率目标 vs 固定仓位**：部分社区成员认为固定仓位在趋势市场中表现更优，波动率目标会在趋势启动初期过度降仓；另一方认为波动率目标的最大回撤控制效果在长期复利下抵消了这一劣势。
- **结构性衰减的识别**：如何在实盘中判断「这次是结构性衰减还是统计性衰减」是最难的问题，社区建议：若市场结构本身发生变化（规则、参与者结构、流动性来源），则倾向于结构性。

## 行动建议

1. **在策略中加入波动率体制过滤器**：计算 20 日实现波动率，在当前波动率超过历史 70th 百分位时自动将仓位缩减至 50%，超过 90th 百分位时退出至现金。
2. **建立信号衰减监控**：每月统计过去 30/60/90 天的滚动胜率，若持续下滑 2 个月以上，执行「是统计性还是结构性衰减」的正式诊断流程。
3. **监控 BTC put skew 作为市场方向早期信号**：当 put skew（put vol - call vol）回落至中性（0-2 vol points），作为看多信号的强化条件之一。
