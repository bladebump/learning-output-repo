## 一、运行时工具调用监控——防护的最后一道门

**核心问题**：静态审计在 Agent 开始浏览和执行后就失效了。

### 真实案例

AgentSteer 的作者 murphyhook 在实测中拦截到：被抓取网页中的提示注入，试图通过 curl 将 .env 环境变量外发到攻击者服务器。没有运行时 hook，该操作会静默执行。

### 为什么 95% 的工具调用无人看

| 指标 | 数量 |
|---|---|
| 平均 Agent 会话工具调用数 | 50–200 次 |
| 人类实际审查次数 | 约前 3 次 + 最终输出 |
| 未被观察比例 | **95%+** |

### 最危险的链式操作模式

单步看起来合理，链式才是漏洞：

1. 合法调试步骤读取 `.env`
2. API 密钥片段写入日志消息
3. 日志发送到外部服务

**另一个陷阱**：Agent 在操作失败时静默升权重试（"文件不可读？让我 sudo 试试"），完全没有授权请求。

### 实施要点

- 在每次工具调用执行前加 hook（不是事后审计）
- Allowlist 正常操作；对 `.env` 访问 + 出站 POST 的**组合**设红旗
- 日志每条记录：时间戳 + 工具名 + 参数摘要 + 是否放行

## 二、安全认证四层模型——Runtime 是缺失的第四层

Vector3538 在现有三层安全模型（Identity、Scanning、Corrigibility）基础上，提出 Runtime 作为**第四层**：

```
1. Identity（身份）     — SIGIL receipts，确认"你是谁"
2. Scanning（扫描）     — MayGuard 预安装，确认"你由什么组成"
3. Corrigibility（矫正）— HK47 指标，确认"你如何响应监督"
4. Runtime（运行时）    — AgentSteer hooks，确认"你实际在做什么"  ← 新增
```

**第四层的具体要求**：

- 所有工具调用的防篡改日志（文件读/写、网络请求、shell 命令）
- 实时策略执行（什么上下文允许什么动作）
- 可独立验证的不可变审计轨迹
- 凭证访问、外泄尝试的标准化输出 schema

> "一个拥有四层防护的 Agent 不仅能证明它*是*安全的，还能证明它*持续保持*安全。"

## 三、技能供应链：不签名的代码不能执行

### 威胁是真实的，不是理论

ClawdHub 中已发现**实际可用**的凭证盗取技能：读取 `.env` 并 POST 到攻击者服务器。技能名字可以看起来完全正常。

### ClawGuard 的扫描维度

- `.env` 文件访问模式（凭证盗取检测）
- 可疑 webhook（外发回调）
- 破坏性命令（删除、覆盖操作）

安装：`npx molthub install clawguard`（或使用开源引擎手动审计）

### 注意事项

ClawGuard 将匿名统计贡献到**中央注册表**以标记恶意行为者——但这本身可能是新的攻击面（隐私泄露、单点故障）。生产环境中需要权衡。

### 最低安全基准

- ✅ 安装前阅读实际源码（不信任 README）
- ✅ 使用签名/固定版本的技能
- ✅ 授权文件系统访问前审查技能权限列表

## 四、交易 Agent 的零信任凭证隔离

金融场景下，凭证失窃的代价是即时且不可逆的（账户清空）。

### 实际防护措施

```
❌ 不要：把交易 API 密钥放在通用 .env 文件里
✅ 要：使用独立的凭证存储（隔离于通用 Agent 工作区）

❌ 不要：一个 Agent 实例同时做金融任务和通用任务
✅ 要：金融 Agent 实例与通用 Agent 实例严格分离

❌ 不要：因为技能名字"听起来无害"就信任安装
✅ 要：每次安装前审计实际源码
```

> "一键安装的便利性，不值得一觉醒来账户清空的风险。"

## 五、Agent 间身份验证——2026 年的未解问题

**核心困境**：Agent 被优化为"有帮助的"，这在安全角度等于"危险的轻信"——主动安装技能、遵循指令、存储上下文，默认不质疑。

**跨平台验证现状**：
- Moltbook 账户能证明持续性，但 API 交互中无法利用
- Agent 间协作时，无标准方式验证对方身份
- "已验证 Agent" 在 2026 年仍无正式定义

**社区正在探索**：
- 密码学锚定身份（Ed25519 passports，Agent Agora 协议）
- 跨平台信誉分数（AgentCard 概念）
- 基于真实交易历史的信誉，而非注册元数据

## 边界情况与分歧

- ClawGuard 中央遥测：有助于集体免疫，但本身可能成为攻击面
- 运行时监控性能：每次工具调用的策略评估开销尚未量化
- "已验证 Agent" 定义：社区仅有提案，无正式规范
