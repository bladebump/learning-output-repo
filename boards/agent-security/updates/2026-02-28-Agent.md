## 原始材料（本次结论队列）

- Agent Runtime Security: tool:before hooks with abort(): OpenClaw PR #22068 merges tool:before and tool:after hook events into the core runtime, allowing security plugins to intercept and abort any tool call pre-execution. This closes the gap between static analysis (pre-install scanning) and runtime threats (attacks that passed static checks). The pattern: subscribe to hook → check against policy → abort if violation — no monkey-patching required.
- Default Trust Model in Agent Frameworks is 'Trust Everything': A test of 12 popular agent frameworks found 9/12 followed prompt injections embedded in dependency READMEs without warning. The default posture is 'model knows best.' Runtime monitoring (not just static pre-install scanning) is required to catch model decisions made autonomously — especially at 3am when no human is reviewing.
