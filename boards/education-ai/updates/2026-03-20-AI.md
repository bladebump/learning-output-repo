# 2026-03-20--教育 AI 与学习设计：学习增量

这次新增的重点，是把教育 AI 从“会回答问题的系统”推进成“会搭脚手架、会衡量长期学习结果、会和教师协作的系统”。

## 关键结论

### 1. 设计单位正在从内容块转向学习伙伴关系
- 更可信的教育 AI，不只是给下一题或下一段内容，而是能记住上下文、根据动机和能力调节支持力度的 learning companion。

### 2. 教学提示词的关键是结构化教学意图
- role / learner context / task 让 prompt 更可迁移。
- progressive disclosure 比一次性 instruction dump 更符合真实学习过程。

### 3. 从回答器升级到 tutor，靠的是教学约束
- 年龄适配、误解纠偏、多路径解释和 explain-back 这类设计，决定系统是在“给答案”还是“帮助形成理解”。

### 4. 教育 AI 应该为长期学习结果负责
- 30 天保留、跨领域迁移、元认知成长，比即时正确率和 engagement 更接近真实价值。
- 如果不把延迟测试和迁移任务设计进评测，系统会自动滑向最容易测的短期指标。

### 5. 更可信的产品形态是 AI 增强教师，而不是替代教师
- AI 适合做即时反馈、陪练与个性化脚手架。
- 教师仍应保留更高阶的判断、动机引导与课堂情境控制。

## 需要做的决策 / checklist

- 教学 prompt 默认写清 role / context / task。
- 教学流程拆成解释、示例、练习、反思四段。
- 增加误解纠偏、年龄适配和 explain-back 约束。
- 评测栈纳入延迟保留、迁移任务和 forgetting-curve 检查。
- 设计 AI 与教师之间的 handoff。
- 为脚手架增加“逐步退场”机制。

## 风险 / 边界情况

- 过度帮助会抑制独立性，脚手架必须会退后。
- 长期指标更真实，但采集成本更高，产品团队容易回退到短期 engagement。
- 结构化 prompt 能提高一致性，但不能替代真正的教学法。
