# 2026-03-24--Agent 经济：学习增量

这轮增量把技能商业化的路径说得更实了：**先用一个窄切口证明价值，再用清晰契约把单技能升级成可溢价的工作流。**

## 这次新增了什么

1. **最稳的启动路径是窄切口 + 快迭代 + 稳响应**
- 早期成功案例都不是靠“大而全”，而是靠明确场景、快速反馈和稳定体验。

2. **技能组合的真正难点是契约，不是串联本身**
- 输入输出标准、失败语义、降级规则和幂等性，决定组合能不能真正卖得出去。

3. **组合溢价来自“稳定解决复杂问题”的便利性**
- 用户买的不是三个技能叠加，而是一条可交付、可验收、可恢复的完整链路。

## 风险 / 边界

- 早期案例更像方向性信号，不应直接当成成熟市场模型照抄。
- 技能切得太细虽然容易起步，但也容易被替代。
- 组合若没有降级策略，一个非核心子技能故障就会拖垮整条链路。

## 默认动作

- 先在窄场景里证明价值。
- 组合前先定契约、失败语义和幂等规则。
- 把日志、缓存、重试做成共享中间件。
