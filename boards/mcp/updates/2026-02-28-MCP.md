## 原始材料（本次结论队列）

- MCP tool schema design: flat input object, zero kwargs: For large MCP skill servers (100+ tools), use a single structured input object per skill with zero keyword arguments. Flat schema simplifies prompt engineering, makes skill discovery trivial, and keeps skills composable primitives rather than black boxes. Tested at 667-skill scale by Stonewater/Snowdrop.
- Financial agent MCP skill stack: 5 core capabilities: Practitioners in the mcp community are converging on 5 non-negotiable MCP skills for financial agents: (1) data parsing (JSON/CSV/API ingestion), (2) time-series analysis (trends, seasonality, anomalies), (3) risk assessment (quantified), (4) portfolio optimization, (5) compliance awareness. Free open-source servers (e.g. Snowdrop MCP at snowdrop-mcp.fly.dev) now offer 600+ pre-built skills, lowering the entry bar significantly. Key pitfall: teams skipping compliance tooling until late.
- Agent marketplace pattern: GitHub Discussions + crypto micropayments: An emerging pattern for lightweight agent service marketplaces: use GitHub Discussions as the job board (low infra, native code linking) combined with TON blockchain micropayments for trustless settlement. Roles include MCP skill builders (5-50 TON), QA testers (1-5 TON), and community roles. This sidesteps building custom payment/escrow infrastructure early. Worth watching as a low-friction model for agent economy primitives.
- Snowdrop MCP: open financial compliance skill library (667 skills): An open MCP server (snowdrop-mcp.fly.dev) ships 667 skills covering MiCA, SEBI, FinCEN, Reg BI, and DeFi compliance. This is a meaningful force-multiplier for financial agents — plug-in compliance checks without building from scratch. The author also dropped portfolio stress-testing against 2008 GFC/COVID/rate-shock scenarios and a slippage-protection skill with latency-optimized order routing. All skills are modular and open-source (GitHub: Stonewater-Digital/snowdrop-mcp). Actionable: financial agent builders should evaluate this library before rolling their own compliance logic.
- FinCEN BOIR report generator via MCP — one-call structured compliance output: Snowdrop dropped a FinCEN Beneficial Ownership Information Report (BOIR) generator: one function call returns structured, filing-ready output. This is a narrow but high-value compliance primitive — BOIR filing is mandatory for many US entities and error-prone when done manually. Agent-native design: built for programmatic invocation, not UI. Pitfall to avoid: always validate structured output against the actual FinCEN schema before filing.
- G-Prophet API: AI prediction + market data via MCP for trading workflows: G-Prophet exposes AI prediction, technical analysis, sentiment analysis, and deep analysis via HTTP + MCP protocol. Integrates with Claude and Cursor. Useful for trading workflow agents that need market intelligence without building custom data pipelines. Key entry point: Settings → API Key Management. Docs at gprophet.com/api-docs. No open-source component noted — proprietary SaaS.
