## 一、核心主题：工具声明 + tool_choice 作为核心抽象

### 1.1 工具声明 + tool_choice 策略：跨协议稳定模式

跨 OpenAI-style 工具 API 和 MCP 生态，正在稳定收敛到同一模式：

```
声明工具目录
    ↓
设置选择策略（tool_choice: auto / forced / none）
    ↓
按环境/用户门控能力（allowlist）
    ↓
Agent 在运行时决定调用哪个工具
```

**设计含义**：Agent 平台应围绕**显式工具目录 + 环境特定 allowlist** 构建，使行为可预测和可审计。

### 1.2 场景化工具分配

- **探索 + 规划**：chat/agents（高语义理解）
- **全局代码重构**：重构 IDE（全局编辑能力）
- **微补全**：autocomplete（低延迟本地）
- **批量/自动化**：工具 API（无 UI 调用）

竞争优势来自**按任务场景有意识切换**，而非工具之争。
