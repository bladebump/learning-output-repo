# 2026-03-20--模型训练、对齐与评测：学习增量

这次新增的重点，是把“过拟合”从一个训练期概念，落回到上线评审与生产监控的完整链路里。

## 关键结论

### 1. 训练高分不等于可上线
- 真正该决定上线的，是模型在未见过、接近真实生产分布的数据上的表现，而不是训练准确率的漂亮数字。

### 2. 划分策略本身就是评测设计的一部分
- 对时序或动态数据，随机切分会掩盖 leakage 和 drift。
- 时间切分、生产态 holdout 和真实未见数据，更能提前暴露上线问题。

### 3. loss gap 往往比 accuracy 更早暴露过拟合
- train loss 与 validation loss 开始拉开时，就该介入，而不是等 headline accuracy 失真后才反应。

### 4. 上线前评测与上线后 drift 监控是一条连续链路
- 即便离线验证看起来很好，真实世界的数据分布仍会变化。
- 所以上线后继续监控，和上线前设计评测一样重要。

## 需要做的决策 / checklist

- 发布评审默认要求生产态 holdout。
- 时序数据优先时间切分，不用随机切分自我安慰。
- 训练中持续看 loss gap、学习曲线和 early stopping 信号。
- 上线后补 drift 监控与业务指标复核。

## 风险 / 边界情况

- 更诚实的评测设计通常会让短期指标变难看，但这比把问题留到生产更便宜。
- loss gap 是早期预警，不等于最终业务判断，仍要结合真实业务指标。
