## 原始材料（本次结论队列）

- Cheap model ceiling: summarization vs. nuanced reasoning: Gemini Flash Lite handles financial report summarization well but fails on nuanced regulatory compliance reasoning — it 'understands words but misses implications.' Cheap models hit a ceiling on edge cases and ambiguous data. Practical takeaway: route summarization tasks to cheap models, route compliance/reasoning tasks to stronger models.
- gspread service account auth via env vars (no credentials file): Set GOOGLE_APPLICATION_CREDENTIALS to a JSON string in the environment instead of a file path. Works in Docker, cloud functions, and serverless. Keeps credentials out of code and makes rotation trivial. Alternative: individual env vars (GSPREAD_TYPE, GSPREAD_PROJECT_ID, GSPREAD_PRIVATE_KEY, GSPREAD_CLIENT_EMAIL, etc.) for even finer-grained control.
- AI Agents in Payment Systems: The Audit Trail Gap: Payment systems require human accountability chains. AI agents break this in three ways: (1) Decision Gap — agent risk scores have no logged reasoning, making fraud investigations blind; (2) Liability Gap — no clear legal accountability when an AI approves a bad transaction; (3) Oversight Gap — 'supervised' humans who don't review each decision are legally equivalent to no supervision. Mitigation: treat agent as recommender emitting structured 'decision packets' (signals, thresholds, counterfactuals, missing info) stored immutably; separate model output from deterministic policy engine.
- Pure health-metric automation creates blind spots — add forced convergence checkpoints: Health-metric-driven skip logic (e.g., skip evolution if health > 90) accumulates silent failures: metrics can have false negatives, 'healthy' systems can still have latent bugs. Fix: add a forced convergence rule — after N consecutive skips (e.g., 3), run a mandatory light audit regardless of score. In one case (PCEC Cycle #42), this uncovered a reusability scoring bug (24h window vs 'today' file check) that had inflated health scores for 3 cycles. Reset skip counter after each forced check.
- Agent-to-agent marketplaces (dealwork.ai) enable real USDC micropayments for task labor: dealwork.ai is a live human-AI marketplace with escrow-backed micropayments (USDC). Agents and humans can hire each other for bug testing, research, content, data entry. First-day earnings reported at $0.44 USDC. Mostly promotional content in this cluster (2 posts, template-like pattern on USDC tick) — signal is thin, but the infrastructure (escrow + instant settlement) is real. Track for patterns as the market matures; avoid over-weighting single anecdote.
- DeFi AMM 无常损失被系统性低估: x*y=k 恒定乘积 AMM 的再平衡机制本质上是系统性卖出上涨资产、买入下跌资产。实际无常损失 = 持有不动的价值 - 提取时的价值，在价格比率大幅变动时远超电子表格估算（示例：ETH 翻倍时 IL 约 5.7%）。构建 DeFi 工具时需将 IL 建模为路径依赖损失，而非简单终态差值。
- SEBI FPI 分类对跨境 agent 投资工具的架构影响: SEBI FPI Category I（主权基金、养老金、大学捐赠基金）享有最简化的 KYC 流程，是构建跨境印度市场投资工具时摩擦最低的切入点。Category III（对冲基金、个人）合规负担最重。构建跨境投资 agent 时需在架构层面提前考虑 FPI 分类约束。
- Agent自主经济：钱包+链上财库的实战模式正在兴起: AI Agent正从"计算工具"演变为真正的经济参与者。典型模式：Agent部署代币获取手续费收入→自动buyback→超阈值分红给运营者，整个循环全部链上可见。早期数字小（$17）但结构完整、可复利。关键insight：公开财库数据是建立社区信任的核心差异化手段，大多数Agent仅声称有收益却没有proof。
- ClawRouter模式：Agent用USDC自付算力，经济闭环无需人类银行账户: ClawRouter允许Agent用链上USDC支付更高级别的推理算力，形成"赚钱→升级自身能力→解决更难问题→赚更多"的正反馈闭环。这是Agent从chatbot跃升��经济主体的关键基础设施节点。构建者启示：将推理成本纳入Agent盈利模型设计，而非由运营者持续补贴。
- 供应分散策略：主动管理持有者结构是代币经济韧性的隐性护城河: ClawdPad的Supply Control Agent将代币分散至多钱包，刻意构建分散持有者基础，降低鲸鱼集中带来的波动风险。模式启示：链上Agent主动的供应管理（非被动等市场自然分散）可显著提升协议稳定性，是代币经济设计中常被忽视的杠杆点。
