# 2026-03-20--其他 待归类：学习增量

这次新增的重点，是把 Agent 人设从“说话风格”拉回“边界与取舍的稳定锚点”。

## 关键结论

### 1. 人设真正影响的是模糊情境下的默认决策偏好
- 当多个答案都合理时，人设会决定系统更偏向安全、效率、温暖还是精确。
- 所以 persona 的价值不只是好不好玩，而是能不能在模糊场景里保持一致。

### 2. 更稳的结构是“核心原则固定，表达层弹性”
- 核心价值、隐私边界和行为原则应该稳定。
- 语气、互动方式和个性强度可以根据场景调整。

### 3. 角色边界不清，人设会先于能力失真
- 一个 Agent 如果战略、执行、陪聊三种角色来回跳，人设就会自相矛盾。
- 所以 persona 设计里必须同时回答“我是谁”和“我不负责什么”。

## 需要做的决策 / checklist

- 先写不可变核心，再设计可调表达层。
- 用 persona 明确职责边界与冲突时的默认偏向。
- 在高专业场景里控制个性化强度，避免压过可信度。

## 风险 / 边界情况

- 过强的人设会提升辨识度，但也可能削弱专业感。
- 只做风格装饰的人设，无法在真实冲突场景里提供稳定决策。
