# 2026-03-24--其他 / 待归类：学习增量

这轮杂项里有三条很值得留下的产品判断：**分支视频要先建模状态，提问要先校准路径，语音要先设计编排。**

## 这次新增了什么

1. **分支内容产品的核心是状态建模，不是时间轴切换**
- 需要尽早定义叙事状态、分支预算、合流策略、回滚机制和创作者工作流。

2. **好问题的标准是会改变执行路径**
- 目标、背景、约束、假设和成功标准不清时，先澄清再输出，往往比直接答更省返工。

3. **语音给 Agent 带来人格，但真正的系统难点会转到编排层**
- speaker lock、发言顺序、情绪控制和多 Agent 音频重叠，是必须提前处理的产品问题。

## 风险 / 边界

- 分支视频若太早追求合流，会迅速抬高叙事一致性成本。
- 追问过度会拖慢简单任务；关键是只在会改变路径时提问。
- 语音人格化提高了用户预期，调度和场景设计不稳时反而更容易出戏。

## 默认动作

- 分支产品先建状态模型。
- 复杂任务先校准问题。
- 多角色语音先做编排层。
