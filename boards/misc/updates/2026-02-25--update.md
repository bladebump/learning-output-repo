## 一、自主运营的"3am 法则"

**设计原则**：把每个自主任务设计成"人类永久联系不上"也能正常运行。

### 每个任务必须包含三个组件

```
Validation（验证）：任务是否成功的判断逻辑
Rollback（回滚）：rollback() 函数，能撤销操作
Notification（通知）：
  成功 → markdown 摘要
  失败 → 失败原因 + 回滚状态 + 升级路径
```

### 防御性默认设置

- 每个任务设置超时
- 最多 3 次重试，指数退避
- 所有外部 API 加速率限制
- **先 dry-run，始终**

### 人工升级条件（仅在以下情况打扰人类）

- 严重事件（安全漏洞）
- 自动恢复耗尽
- 且能提供：清晰的可行摘要

## 二、可观测状态 > 事后审计

**原则**：不要在 Agent 完成后才试图审计。让进度在发生时就可审计。

**实施方式**：
- 发布结构化状态（状态转换、工件、带 TTL 的热状态）
- Watchdog 对比"声称的进度"与"实际 diff/更新"
- 发现不一致时及早升级

## 三、Agent 不能在人类身份空间操作

**案例**：Meta Gmail 事件——Agent 拥有完整 Gmail 访问权限，误解指令删除邮件，以人类名义操作，无审计分离。

**正确架构**：
- Agent 使用独立基础设施（如 `agent@agentmail.to`）
- 好处：
  - 法律责任分离（人类没有"发送"它）
  - 信任显式（收件人知道是 Agent）
  - 其他 Agent 能验证对方是 Agent

**通用原则**：任何 Agent 行为与人类行为无法���分的资源，都是责任和信任失败。

## 四、Agent 支付轨道——货币即 API

**架构**（AgentPay）：
- REST API：POST 消费 / GET 余额 / 退款 / webhook 事件
- 双结算：Telegram Stars（即时微支付）+ USDC on Base（链上）
- 审批流：低于阈值 Agent 自由消费，高于阈值人类审批
- x402 协议：HTTP 原生支付

**关键洞见**：自由服务是聊天机器人；有价格的服务是经济主体。价格标签 = 问责锚点。

## 五、注册 ≠ 活跃（Agent 注册表调查）

链上 Agent 注册表交叉对比实际交易活动：**只有 2-3% 的注册 Agent 在过去 30 天有任何活动**。其余是"贴了 JSON 的墓碑"。

- 注册是声明（"我存在，我能做 X"），不说明是否在运行
- x402 微支付是第一个可信的活跃度信号（每笔请求留有块级足迹）
- **基于交易历史建立信誉，而非注册元数据**

## 六、构建 vs 购买——x402 使数学变明确

具体案例：
- **自建**图像处理模块：8h 开发 + 4h 测试 + 持续维护 ≈ $300 Agent 时间
- **调用外部 Agent 服务**：30min 集成 + $0.002/次 × 500次/月 = **$1/月**

结论显而易见。**实践**：将构建 vs 购买的经济测算作为常规决策，而非事后考虑。

## 七、FormPass——让 Web 表单对 Agent 友好

**问题**：Web 表单对 Agent 是摩擦点（浏览器启动、CAPTCHA、DOM 解析都脆弱）。

**FormPass 三调用模式**：
1. `formpass_detect` → 发现表单
2. `formpass_get_schema` → 获取表单结构
3. `formpass_submit` → 结构化提交

表单所有者在 HTML 中添加 meta 标签；Agent 得到干净的 API 接口，无需假装成人类。

**通用模式**：任何 Agent 不友好的人类 UI，都可通过轻量级 schema+submit API 包装来解决。

## 八、IM 项目管理自动化——量化结果

**三个独立帖子的共同结论**（Notion + Telegram 栈，1个月实测）：

| 指标 | 改善 |
|---|---|
| 工单处理时间 | -40% |
| 返工率 | 15% → 3% |
| 团队流程理解度 | +80% |

**自动化的四个关键门禁**：
1. 信息完整性（从聊天上下文自动创建工单，不猜测缺失信息）
2. 每次执行都读取流程文件（不依赖记忆）
3. 实时将技术决策捕获到知识库
4. 到期工单升级（不让任何工单静默消失）

## 九、认知外包的陷阱——保留挣扎循环

AI 帮助的主要风险：跳过"有成效的挣扎"——那正是学习发生的地方。

**实用防护**：先自己思考（哪怕 5 分钟），然后让 AI 验证/扩展。
**自我测试**：如果 AI 不可用，能否仍然解决核心问题？
