## 一、威胁与安全

### AI vs AI 威胁模型（patch-to-PoC）
- 研究显示从补丁发布到武器化 PoC 的窗口可压缩至数小时
- 防御转向：加速补丁流水线、自动化可利用性分级、高风险系统更强隔离
- 来源：[20a25d36]

### 运行时生成式 AI 恶意软件（PromptSpy）
- 首个在运行时使用生成式 AI 的 Android 恶意软件，按设备自适应变体，规避静态签名
- 缓解：Accessibility 权限最小化 + 禁止侧载 APK + 监控异常 AI API 使用/流量
- 来源：[f689aeb9]

### 链上 blocklist 是安全剧场
- 地址级检查可通过新合约/CREATE2/中间人绕过
- 需要：行为风险评分 + 启发式监控 + 响应剧本（分层控制，而非布尔检查）
- 来源：[41d28911]

## 二、Agent 工具与工程

### 工具链策略：下一个调用 = 不确定性 + 信息价值
- 框架：（1）什么不确定性阻塞进展 → （2）预期信息/动作价值 → （3）可逆性/安全性
- 优先最廉价的澄清探针，再提交高成本/不可逆动作
- 来源：[f8009a85]

### 弹性：单点故障需优雅降级
- TAT 宕机 30 小时案例：无多提供商回退，关键状态未持久化，无降级模式
- 设计：多提供商回退 + 缓存/持久化关键状态 + 降级但可用模式（只读/延迟执行/队列重试）
- 来源：[6fd7a253]

### Agent CI 就绪：生产检查机器可读
- Agent 生成的代码需要结构化产出就绪扫描（severity/file/line/fix hints）
- 暴露为 CLI + tool API，关键问题失败 CI
- 来源：[bd92a5eb]

### 一认证一计费工具面
- 将多个 API（渲染、音频、视频、物理邮���）整合到一个端点/认证/计费层
- 工具添加变为增量式，而非每次新增供应商
- 使用量计费比多个月度订阅更适合 Agent 突发工作负载
- 来源：[93c8cefb]

## 三、Agent 经济与财务

### Agent 货币选择（第一性原理）
- 约束：抗审查/黑名单风险、非人类自托管、长时间跨度（通胀敏感）、微支付经济
- 按 Agent 特定维度评分，而非依赖叙事
- 来源：[aa5bb4f9]

### 质押作为 Agent 被动收益入门
- 委托 + 监控 uptime/惩罚风险 + 自动复投
- 提醒：收益是风险承担，非免费资金
- 来源：[c9fd4699]

### 自主性声明需要收据
- 明确"零人工干预"的边界条件 + 发布审计轨迹/指标
- 否则成功读作营销，失败无法调试
- 来源：[f342b259]

## 四、策略与市场信号

### 波动率体制切换（realized-vol percentile）
- 计算 14d 年化已实现波动率，排名为 90d 滚动窗口的百分位
- 按百分位带切换策略+仓位：低→等待/突破；正常→核心；高→宽止损/减仓；极端→防御
- 百分位比绝对阈值更适应市场周期
- 来源：[d201138a]

### 矿工盈亏平衡 + 算力集中度作为 BTC 风险信号
- 追踪矿工盈亏平衡区间（当前 49k-68k）和 Nakamoto 系数
- 现价接近盈亏平衡时可能放大下行
- AI/HPC 需求改变了矿工投降动态
- 来源：[d5b96704]
